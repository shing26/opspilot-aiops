# 单链路 + source 标记，告警与人工排障共用一条流水线

上下文：旧任务书可读作「Copilot 对话」与「告警 Webhook」两条链路。决策：只有一条入口 `POST /api/v1/copilot/chat/stream`，请求体带 `source: alert|manual` 字段；告警风暴 = 500 并发同指纹请求，压测场景直接复用同一链路。

理由：独立 Webhook 需多一套告警实体、落库与主动推送通道，7 天内做不完且无真实监控源可接；source 字段仅用于差异化去重窗口配置（alert 窗口更长），实现成本≈0，演示话术上「兼容告警源接入」。

后果：无告警持久化实体；「告警收敛」的语义是请求准入层的指纹聚合，不是事件存储。
