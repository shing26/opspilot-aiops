# SSO 令牌被下游拒绝（时钟漂移特征库）

## 适用症状

- 部分用户登录成功但访问业务系统报 `52002_SSO_TOKEN_REJECTED`，且同一用户**重试时好
  时坏**；
- 日志中拒绝原因分散在多台下游实例，非集中爆发。

## 排查步骤

1. 判断分布：按下游实例聚合拒绝数——若均匀分布，优先怀疑**新扩容实例组**的时钟偏差
   （令牌 `nbf/exp` 校验容忍窗口 ±60s）；
2. 在嫌疑实例执行时间源检查（NTP offset 应 < 500ms）；容器化实例注意宿主迁移后
   chrony 未重新同步的窗口期；
3. 单实例集中拒绝 → 核对该实例加载的签名验证密钥版本号是否与 SSO 签发端一致
   （密钥轮换后旧版本缓存未失效是既往根因，见 ac-602 复盘）；
4. 全量集中拒绝 + 上游无变更 → 检查 SSO 与下游之间的 CDN 缓存是否把 `401` 响应
   缓存回源（响应头 `age > 0` 即命中）。

## 止损操作

- 时钟问题：强制 NTP 同步并滚动重启该实例组的令牌校验缓存；
- 密钥版本：调用 SSO 管理端点推送失效通知（需 secops 角色）；
- CDN 缓存 401：临时给 `/session/*` 路径加 `Cache-Control: no-store` 覆盖规则。

## 关联工单

- 每季度轮换窗口后 24h 内的批量出现属预期，按演练预案处理，不算故障。
