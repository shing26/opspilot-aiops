# 对象存储配额超限（媒体上传拒绝）

## 适用症状

- 上传接口报 `52003_BUCKET_QUOTA_EXCEEDED`，但控制台用量曲线未触顶；
- 多发生在活动日，上传成功率阶梯下跌。

## 排查步骤

1. 区分配额维度：该错误码覆盖**存储量**与**请求数**两条配额线，响应头
   `x-quota-dim` 指明触顶维度——请求数触顶的常见根因是缩略图重复生成（见步骤 3）；
2. 存储量触顶：按前缀聚合用量，重点查临时目录 `tmp/`（历史上传失败残留，本桶
   生命周期规则只覆盖 `cache/` 前缀）；
3. 请求数异常放大：比对网关侧请求数与处理侧任务数，若任务数明显更多 → 缩略图生成
   在重试风暴中重复执行（幂等键缺失），修复合成事件消费逻辑而非扩配额；
4. 确认无外部盗链：按来源 IP 聚合上传 UA，活动日媒体外链常被爬虫复用。

## 止损操作

- 临时提额走审批单 QTA-9（45 分钟内生效），同时必须挂上生命周期清理规则，
  否则提额只是把触顶时间推迟 3 天；
- 幂等缺陷止血：关闭「重试生成缩略图」开关（`acme.media.thumb-retry`），接受部分
  历史对象无缩略图。

## 常见误判

- 把请求数触顶当存储量触顶处理，删了一堆冷数据配额仍然秒爆。
